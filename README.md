# Top Academy — Smart Swimmer Nutrition

نظام إدارة تغذية رياضية متكامل للسباحين، من إعداد **د. وليد عبد الرحمن عبد الظاهر**. مبني بـ **Next.js 15 + TypeScript + Tailwind CSS + Prisma**، بواجهة عربية RTL بالكامل.

## المميزات

- **حساب علمي للاحتياجات**: Mifflin-St Jeor / Katch-McArdle لـ BMR، عامل النشاط × BMR = TDEE، سعرات التمرين عبر METs، وتعديل حسب الهدف (منافسة/تضخيم/تنحيف/صيانة).
- **خطة غذائية مخصصة أسبوعية** مولّدة من قاعدة طعام عربية (~76 صنفًا) مع بدائل، قائمة مشتريات، وملاءمة الحساسية والمكروهات.
- **حماية علمية إلزامية**: لا توجد خطة قبل إكمال `SwimmerProfile`؛ القاصرون وأصحاب الحالات الصحية يحصلون على `medicalAlert` وخطة إرشادية فقط.
- **تحليل وجبات بالكاميرا** عبر AI (OpenAI / Gemini / وضع Mock تجريبي بدون مفاتيح)، مع تعديل يدوي للنتائج وإضافتها للسجل.
- **سجلات يومية**: طعام، ماء، تدريب، استشفاء (نوم/طاقة/توتر)، وزن — مع أهداف مباشرة.
- **تقارير أسبوعية/14/30 يومًا**، وضع بطولة، دليل مكملات تثقيفي، إشعارات وتفضيلات PWA، و**تصدير PDF عربي** (خط Cairo) لخطة السباح.
- **أدوار ولوحات**: سباح، مدرب (إدارة رياضيين ومتابعة)، اختصاصي تغذية، ومشرف (Admin).

## التقنيات

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS · Prisma 5 · NextAuth v4 · zod · pdfmake + Cairo · bcryptjs · SQLite (محلي) / PostgreSQL (إنتاج)

## التشغيل السريع

> **ملاحظة Windows PowerShell:** إذا فشل `npm` بسبب سياسة التنفيذ، استخدم `npm.cmd` بدلًا من `npm`.

```bash
# 1) التثبيت
npm install

# 2) إعداد البيئة
copy .env.example .env        # ثم عدّل القيم حسب الحاجة

# 3) قاعدة البيانات (SQLite افتراضيًا — بدون خادم خارجي)
npm run db:generate
npm run db:push
npm run db:seed

# 4) التشغيل
npm run dev                   # http://localhost:3000
```

## الذكاء الاصطناعي (تحليل الوجبات)

يعمل النظام بوضع **Mock** افتراضيًا (لا يحتاج مفاتيح). لتفعيل مزود حقيقي:

```
AI_PROVIDER="openai"      # أو "gemini"
OPENAI_API_KEY="sk-..."
GEMINI_API_KEY="..."
```

المفاتيح تُقرأ من `process.env` على الخادم فقط ولا تصل إلى المتصفح أبدًا.

## النشر (إنتاج)

1. `npm run build`
2. اختر قاعدة البيانات: استخدم **PostgreSQL** في الإنتاج — عدّل `DATABASE_URL` في `.env` ثم نفّذ `npm run db:postgres` و`npm run db:push`.
3. استبدل `NEXTAUTH_SECRET` بقيمة طويلة عشوائية (`openssl rand -base64 32`) و`NEXTAUTH_URL` بالرابط الفعلي.
4. شغّل `npm run start` (أو عبر Vercel/Railway/منصة أخرى تدعم Next.js).

> خط الترويسة في التصدير: يجب أن يكون ملف الخط `src/services/pdf/fonts/Cairo.ttf` موجودًا (متضمن في المشروع).

## الأمان والمسؤولية

- كل مدخلات الواجهات تُتحقق عبر `zod`، وكلمات المرور مشفّرة بـ bcrypt، وبيانات جلسات NextAuth مشفّرة، مع تسجيل `AuditLog` للأحداث الحساسة.
- المحتوى تثقيفي **إرشادي ولا يُغني عن استشارة الطبيب أو اختصاصي التغذية**؛ راجع صفحة الإخلاء الطبي في التطبيق.
